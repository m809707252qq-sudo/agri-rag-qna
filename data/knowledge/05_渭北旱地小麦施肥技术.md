# 渭北旱地小麦施肥技术

## 一、区域特点

渭北旱塬包括陕西咸阳、宝鸡北部及甘肃东部，属暖温带半湿润易旱区，年降水量500–600毫米，主要集中在7–9月，小麦生育期降水仅200–250毫米，属典型雨养农业区。

小麦生产的主要限制因子是：**干旱、土壤瘠薄、肥力不均**。因此施肥应遵循"以肥调水、有机肥与化肥结合、氮磷配合、适期追肥"的原则。

## 二、需肥规律

小麦一生对氮、磷、钾的吸收比例约为 **N : P₂O₅ : K₂O = 3 : 1 : 2.5**。

- **出苗至越冬**：吸收氮磷较少，但对磷敏感，缺磷影响分蘖和次生根。
- **返青至拔节**：进入第一个需肥高峰，氮素吸收量占总吸收量的30%–40%。
- **拔节至抽穗**：需肥高峰期，氮、钾吸收均占总量的50%以上。
- **抽穗至成熟**：氮素仍有吸收，磷钾吸收减弱，需进行叶面补肥。

## 三、推荐施肥方案（亩产400公斤目标）

### 1. 基肥（底肥）

结合深翻整地一次施入：

| 肥料 | 每亩用量 | 说明 |
|---|---|---|
| 腐熟有机肥（厩肥/堆肥） | 2000–3000公斤 | 改良土壤、保水保肥 |
| 尿素（含N 46%） | 10–12公斤 | 占总氮量的60% |
| 磷酸二铵（含N 18%、P₂O₅ 46%） | 15–20公斤 | 磷素主要来源 |
| 氯化钾（K₂O 60%） | 5–8公斤 | 旱地产田钾素不足时补施 |
| 硫酸锌 | 1–1.5公斤 | 预防缺锌"花白苗" |

施肥方法：有机肥全部底施；化肥深施至10–15厘米土层，避免撒施表土造成挥发和流失。

### 2. 追肥（关键期）

#### （1）返青拔节肥（氮肥后移）
- 壮苗田：返青期不追肥，**拔节期（3月中下旬）每亩追尿素8–10公斤**，可显著提高成穗数和穗粒数。
- 弱苗田：返青期（2月下旬至3月上旬）提前追尿素5–7公斤，促弱转壮。
- 旺苗田：推迟追肥至旗叶露尖，控制氮肥用量。

#### （2）扬花灌浆期（叶面喷肥）
抽穗至灌浆期，结合防病喷药进行叶面补肥：

- **0.2%–0.3% 磷酸二氢钾溶液**，每亩50公斤，间隔7–10天喷1–2次，可防干热风、增粒重。
- 脱肥麦田可加 1%–2% 尿素溶液混喷。

## 四、注意事项

- **切忌"一炮轰"**：旱作区氮肥全部底施会造成前期旺长、后期脱肥，应坚持"底肥+拔节肥"两次施用。
- **适期播种与施肥配套**：渭北旱塬适宜播期为9月15日–10月5日，播种过早易遭冻害和纹枯病。
- **播量控制**：亩基本苗控制在15–20万，晚播可适当增加至22–25万。
- **有机肥必须腐熟**：未腐熟有机肥带菌带虫，且易烧苗。
